GitHub, without the browser.

Rivet is a native GitHub client written in Rust. Repositories, pull requests, issues, Actions and notifications look the way they do on github.com, but every screen is drawn natively with egui. There's no web view underneath.

Download Rivet View the source

Windows · macOS · Linux · Android. Free and open source.

A tour of Rivet

Review pull requests where you work.

Read the conversation, step through commits, check runs and changed files, leave line comments, then approve or request changes. Merge with any method the repository allows, or flip a draft to ready.

Triage issues with GitHub's own queries.

Filter with the same qualifiers you type on github.com. Open issues from templates and YAML forms, comment, react, set labels, assignees and milestones, and close as completed or not planned.

Watch Actions without refreshing.

Browse workflows, runs, jobs and steps. Search through logs, dispatch a workflow with typed inputs, re-run or cancel. Running jobs update on their own.

Also in the box

Local git
Clone, commit, branch, merge, push and pull, with a visual merge conflict resolver. Desktop only.
Notifications
An inbox with reason and repository filters that jumps straight to the issue, PR or run.
Search
Code, repositories, issues, pull requests, users and commits, with GitHub's qualifiers.
Keyboard first
A command palette on Ctrl K that takes pasted github.com links, plus GitHub's own shortcuts like g n.
Several accounts
Sign in with GitHub in the browser and switch accounts from the avatar menu. Tokens stay in your OS keychain.
Repository files
Editors for the README, issue and PR templates, labels, branch protection and community files.

Download

Every release ships ready-built archives. Pick yours from the latest release.

  • Windowsx86_64-pc-windows-msvc.zip
  • macOS, Apple siliconaarch64-apple-darwin.tar.gz
  • macOS, Intelx86_64-apple-darwin.tar.gz
  • Linuxx86_64-unknown-linux-gnu.tar.gz
  • Android 8.0+android.apk

Or build it yourself with a stable Rust toolchain:

git clone https://github.com/xRookieFight/Rivet.git
cd Rivet
cargo run --release
