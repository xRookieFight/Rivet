# Rivet 0.1.0

The first release of Rivet, a native GitHub client written in Rust. Every screen follows github.com and is drawn natively with egui, with no web view underneath.

Available for Windows, macOS (Apple silicon and Intel), Linux and Android.

## Signing in

* Sign in with GitHub in the browser through the OAuth device flow.
* Personal access tokens, and on desktop the token from the GitHub CLI.
* Several accounts, switched from the avatar menu.
* Tokens live in the OS keychain (Keychain, Credential Manager, Secret Service, Android Keystore). Only the login and avatar URL are written to the preferences file.

## Dashboard and navigation

* Dashboard with top repositories, organizations, contribution graph, pinned repositories, activity feed and inbox summary.
* Command palette on Ctrl/⌘ K that accepts `owner/name` and pasted github.com links.
* GitHub's keyboard shortcuts (`/`, `g d`, `g n`, `g i`, `g p`), plus back and forward history.
* Light, dark and system themes, picked under Settings, Preferences.

## Repositories

* File browser, README, and an About sidebar with languages and releases.
* File viewer with syntax highlighting, and an in place editor that commits directly or to a new branch with a pull request.
* Branches, tags, releases, commit history and single commit diffs.
* Star, watch, fork, create, edit settings, change visibility, archive and delete.
* Files tab with managers for the README, issue and PR templates, community files (LICENSE, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, FUNDING.yml), .gitignore, .editorconfig, CODEOWNERS, Dependabot and workflows, plus labels and branch protection rules.

## Issues and pull requests

* Issues with query based filtering, issue templates and YAML issue forms, comments, reactions, labels, assignees and milestones. Close as completed or not planned.
* Pull requests with branch comparison and PR templates, a conversation timeline, commits, checks and changed files.
* Line review comments, approve or request changes, reviewers, draft to ready, and merging with any method the repository allows.

## Actions

* Workflows, runs, jobs and steps, with log search.
* Manual dispatch with typed inputs, re-run and cancel.
* Running jobs refresh on their own.

## Notifications and search

* Inbox with reason and repository filters, mark read, mark done and unsubscribe. Opening one jumps straight to the issue, PR or run.
* Search across code, repositories, issues, pull requests, users and commits with GitHub's qualifiers.

## Local git (desktop)

* Clone and open local repositories.
* Stage, unstage and commit. Fetch, pull and push.
* Create, switch, merge and delete branches, manage remotes and browse history.
* Visual merge conflict resolver.

## Android

* Same app as on desktop, built with GameActivity, with the soft keyboard and the system's certificate verification.
* Local git and native file dialogs aren't available on Android yet, so those actions are hidden there.
* Known issue: copying to the clipboard doesn't work on Android yet.
